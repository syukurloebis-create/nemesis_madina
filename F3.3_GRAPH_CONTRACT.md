### 2.5 Key Actors

```
GET /api/v1/graph/cases/{case_id}/key-actors?limit=10
```

**Response:**

```json
{
  "case_id": "...",
  "items": [
    {
      "entity_id": "uuid",
      "name": "...",
      "entity_type": "vendor",
      "degree": 42,
      "risk_score": 0
    }
  ],
  "total": 10,
  "method": "degree_centrality"
}
```

**Notes:**
- `method` = `"degree_centrality"` (v1)
- Formula: `degree = count(relationships where source_id = entity_id or target_id = entity_id)`
- **BUKAN** hardcoded "influence" 85/72
- Case-scoped

### 2.6 Graph Risk (Analytical)

```
GET /api/v1/intelligence/graph-risk/{case_id}
```

**Response:**

```json
{
  "case_id": "...",
  "status": "OK",
  "analytical_graph_risk": 43.48,
  "level": "MEDIUM",
  "components": {
    "entities": 4177,
    "relationships": 2424,
    "density": 0.5803
  },
  "calculated_at": "..."
}
```

**Notes:**
- **Label: `analytical_graph_risk`** — BUKAN `overall_case_risk`
- Ini adalah **view analitik**, bukan canonical risk score
- Canonical risk score tetap di `/api/v1/risk/explanations/{case_id}`
- Jika `graph_risk` di Risk Engine berbeda (100 vs 43.48), itu **expected** — dua konteks berbeda
