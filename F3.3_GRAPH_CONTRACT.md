### 1.3 Read Owner

**Canonical read owner:** `PostgresGraphRepository`
**File:** `backend/graph/infrastructure/repositories/postgres.py`

**Read path (actual):**

```
HTTP request
    ↓
GraphReadService (application boundary)
    ↓
PostgresGraphRepository.get_by_case(uow, case_id)
    ↓
SELECT * FROM graph_entities    WHERE case_id = :case_id
SELECT * FROM graph_relationships WHERE case_id = :case_id
    ↓
OrmToGraphMapper → GraphAggregate (full case-scoped aggregate in memory)
    ↓
GraphReadService applies [:limit] at application boundary
    ↓
HTTP response (bounded/truncated)
```

**Application boundary:** `GraphReadService`
**File:** `backend/services/graph_read_service.py`

### 1.4 Read Semantics — v1

**v1 implementation is a bounded/truncated case-scoped read, not DB pagination.**

- Full case-scoped `GraphAggregate` is loaded via `GraphRepository.get_by_case()`.
- Limit is enforced **at the application boundary** (`[:limit]` on the aggregate’s nodes/edges), **not** in SQL.
- No `LIMIT`, `OFFSET`, `cursor`, or `page` in the repository query.
- No field-level filtering at DB level.
- No `search` support.
- Baseline dataset (4177 / 2424) fits comfortably in memory for this implementation.

DB-level pagination, cursor, and field-level filters are **explicitly out of scope for v1** and tracked as future technical debt.

### 3.7 Collusion

`GET /api/v1/graph/cases/{case_id}/collusion`

```json
{
  "case_id": "b4897392-87ab-4e7a-84b6-90228f3d1eb9",
  "collusion_relationships": [
    {
      "id": null,
      "source": "...",
      "target": "...",
      "relationship_type": "COLLUSION",
      "weight": 1.0,
      "amount": null,
      "description": null,
      "extra_data": {}
    }
  ],
  "collusion_relationship_count": 4,
  "detection_backed": false
}
```

**Semantics (F3.3 LOCKED):**

- `COLLUSION` **relationship edges** ≠ `COLLUSION` **detections**.
- Endpoint performs bounded relationship read (`limit=10000`), then applies `relationship_type == "COLLUSION"` filter **post-read**, at the application boundary.
- **Bukan** database query `WHERE relationship_type='COLLUSION'`.
- Baseline: 4 COLLUSION edges; 0 rows in `collusion_detections`.
- `detection_backed: false` = explicit bahwa detections tidak di-back oleh record di table `collusion_detections`.
